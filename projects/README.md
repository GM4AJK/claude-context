## gps-staff.md

DIY RTK GNSS survey staff — base + rover PCBs (STM32F765VIT + ZED-F9P + SX1262), ESP32-S3 Zero comms bridges, ESP32-S3 4.3" handheld controller. Covers comms architecture (GFSK RTCM, BLE, ESP-NOW), LVGL widget pattern, STM32 firmware conventions, IDF 6 build setup, and current hardware/firmware status.
